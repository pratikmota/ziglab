A function is a named block with a type for each argument and a type for what it returns.

`void` means “no value comes back.” `pub fn main() void` is the entry point you already know: public, so the runtime can call it, and it returns nothing.

A helper in the same file can stay private — omit `pub`. Other files cannot call it. Return a value with `return`.

```zig
const std = @import("std");

fn add(a: i32, b: i32) i32 {
    return a + b;
}

pub fn main() void {
    const sum = add(2, 3);
    std.debug.print("{d}\n", .{sum});
}
```

Arguments are `const` unless you write `var` in the parameter list. One return type for now. You will see error unions (`!`) in a later chapter.
