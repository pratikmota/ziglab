  - id: q2
    prompt: "Why does main usually start with pub?"
    options:
      - id: a
        text: "So the runtime (or other code) can call it. Without pub, main stays private to the file."
      - id: b
        text: "pub means the function returns a value."
      - id: c
        text: "pub turns on the garbage collector for that function."
    answer: a
    explain:
      a: "Correct. pub is visibility. The entry point has to be visible."
      b: "The return type is written after the parentheses, like void."
      c: "Zig does not have a garbage collector."
