A Zig program that prints a line is already a complete program.

**The entry point.** `pub fn main() void { ... }` is where the program starts. `fn` declares a function. `pub` means other code — here, the runtime — may call it. `void` means this `main` does not return a value.

**Import.** `const std = @import("std");` loads the standard library at compile time and binds it to the name `std`.

**Print.** `std.debug.print` writes a message. The first argument is the text. `\n` is a newline. The second argument is a list of values to fill into the text. For a fixed message, that list is empty: `.{ }`. You will fill it when you print a number in the next chapter.

```zig
const std = @import("std");

pub fn main() void {
    // Change Hello, ZigLab to Hi, ZigLab on the next page.
    std.debug.print("Hello, ZigLab\n", .{});
}
```

Read it top to bottom. There is no hidden class and no implicit `main` from a file name. The next page puts this in an editor so you can change the message and Run.
