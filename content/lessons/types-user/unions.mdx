A **union** holds one of several payloads. A **tagged** union (`union(enum)`) remembers which one, so you cannot read the wrong field by accident.

```zig
const std = @import("std");

const Slot = union(enum) {
    empty,
    qty: i32,
};

pub fn main() void {
    const slot: Slot = .{ .qty = 4 };
    const n = switch (slot) {
        .empty => 0,
        .qty => |q| q,
    };
    std.debug.print("{d}\n", .{n});
}
```

`.empty` has no extra data. `.qty` carries an `i32`. `switch` unwraps the payload with `|q|`.

You do not need a pointer to store a union in a local. Untagged unions exist for C layouts; skip them until you are matching a C ABI. This page is the peek: **one tag, one payload, switch to read it.**
