An error is a **value**, not a stack unwind you forgot about. A function that might fail returns an **error union**: `error{Range}!i32` — either an `i32` or an error from that set.

**`?T`** means missing. Fallback: **`orelse`**.  
**`!T`** means failed. Fallback: **`catch`**.

`try` unwraps an error union or returns the error to the caller. That only works when the caller’s return type can hold the error (`!void`, not `void`). `catch` stays in the function and supplies a fallback.

```zig
const std = @import("std");

const Fail = error{ Empty };

fn load(ok: bool) Fail!i32 {
    if (!ok) return error.Empty;
    return 9;
}

pub fn main() void {
    const n = load(false) catch 0;
    std.debug.print("{d}\n", .{n});
}
```

`load(false)` fails. `catch 0` turns that into `0`. `orelse` would not compile here — this is `!`, not `?`.
