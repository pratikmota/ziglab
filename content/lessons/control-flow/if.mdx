`if` chooses a path. The condition must be a **bool** — the same `true` / `false` you compared in Values.

```zig
const std = @import("std");

pub fn main() void {
    const temp: i32 = 18;
    if (temp >= 20) {
        std.debug.print("warm\n", .{});
    } else {
        std.debug.print("cool\n", .{});
    }
}
```

You can also use `if` as an **expression**. Both branches must produce the same type. That is how you bind a name to the result instead of printing from two places.

```zig
const std = @import("std");

pub fn main() void {
    const temp: i32 = 18;
    const label = if (temp >= 20) "warm" else "cool";
    std.debug.print("{s}\n", .{label});
}
```

`{s}` prints a string. `{d}` is still for numbers — mixing them up is a compile error.

`else if` chains extra tests. There is no truthy integer: `if (1)` does not compile. Compare, then branch.
