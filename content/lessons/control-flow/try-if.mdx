The starter binds `temp` and builds a label with `if` as an expression: `"warm"` when the reading is at least 20, otherwise `"cool"`.

Run it. The print uses `{s}` because the value is a string, not a number. You can change `temp` to see the other branch; leave it at 18 if you want the line below.
