Zig’s C story is a reason people pick the language: **call C, and be called from C**, without a second FFI language in the middle.

`@cImport` translates a C header at compile time. You then call those functions as Zig functions, link the C objects, and pick a libc when you need one. The Language Reference section [Import from C Header File](https://ziglang.org/documentation/0.16.0/#Import-from-C-Header-File) is the canonical write-up.

**You cannot Run `@cImport` here.** The playground has no C compiler, no system headers, and no linker for mixed objects. A snippet that starts `@cImport({ @cInclude("stdio.h"); })` belongs on a machine with Zig installed.

C++ is out of this path. When you leave the lab, install Zig, then import C from a local `build.zig` — not from this editor.
