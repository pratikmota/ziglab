An array holds a **fixed** number of values of one type. The length is in the type: `[3]i32` is three signed 32-bit integers, not “a list that might grow.”

```zig
const std = @import("std");

pub fn main() void {
    var nums = [_]i32{ 10, 20, 30 };
    nums[1] = 21;
    std.debug.print("{d}\n", .{nums[1]});
}
```

`[_]` asks Zig to count the literals. `nums.len` is `3`. Indexes start at `0`. Out-of-range indexes are illegal in safe builds — same tone as overflow: Zig would rather stop you than invent a slot.

This is not a resizable list. `ArrayList` in the standard library comes later, on a machine with an allocator. Here, the length is known when you write the array.
