`"lab"` looks like a string. In Zig it is **bytes**: a sequence of `u8`. There is no `String` class, no hidden length object, and no character type that is not an integer.

Print a string with `{s}`. `{d}` is for numbers. Mixing them up is a compile error, which is the compiler being useful.

```zig
const std = @import("std");

pub fn main() void {
    const msg = "lab";
    std.debug.print("{s} len={d}\n", .{ msg, msg.len });
}
```

`msg.len` is `3` — three bytes. Many Unicode characters take more than one byte. Indexing a “letter” by `msg[i]` is indexing a **byte**, not a grapheme. For this path, treat text as bytes and keep messages in ASCII unless you mean to handle UTF-8 later.

A sentinel-terminated pointer (`[:0]const u8`) shows up in C interop. You do not need that for `"lab"` in `main`.
