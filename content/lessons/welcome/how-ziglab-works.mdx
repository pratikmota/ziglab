ZigLab is a **guided path** plus a **playground**.

Each chapter is a handful of short pages. A **concept** page is reading: one idea, in plain language. Later chapters add **try** and **challenge** pages with an editor, and a **quiz** at the end of the chapter. Chapter 01 is concepts and a quiz only. There is no editor here on purpose.

You can go in order with Previous and Next, or jump from the sidebar. Nothing is locked.

Progress is saved in **this browser** (`localStorage`). There is no account and no sync. Another device, another browser, or a cleared site store starts you over. That is the whole privacy model for v1.

Some lessons may offer **Watch a walkthrough**. If a lesson has no video, you will not see an empty player. The playground (when it is connected) is for trying an idea without a lesson around it. Until a real in-browser compiler lands, Run is an honest preview, not a pretend compiler.

If a page looks wrong, use **Report a problem**. It opens a GitHub issue with the lesson id and URL. It never pastes your editor code into the link.
