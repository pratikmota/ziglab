ZigLab is a **guided path** plus a **playground**.

Each chapter is a handful of short pages. A **concept** page is reading: one idea, often with a small snippet. **Try** and **challenge** pages add an editor. A **quiz** sits at the end of the chapter.

Chapters **1–6** are the **core path**: enough Zig to write small programs in this browser. Later chapters add structs, pointers, errors, and comptime.

You can go in order with Previous and Next, or jump from the sidebar. Nothing is locked.

Progress is saved in **this browser** (`localStorage`). There is no account and no sync. Another device, another browser, or a cleared site store starts you over.

The playground compiles Zig **in this browser**. Home never downloads the compiler. It is a learning sandbox, not ziglang.org.

You do **not** need Zig installed to learn here. When you leave the lab — real `zig build`, `zig test`, files, C linking — install a matching 0.16.x from [ziglang.org/download](https://ziglang.org/download/) and use any editor with a Zig extension. Next you write a real program in the editor.

If a page looks wrong, use **Report a problem**. It opens a GitHub issue with the lesson id and URL. It never pastes your editor code into the link.
