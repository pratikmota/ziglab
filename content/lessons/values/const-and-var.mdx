A name in Zig is either **const** or **var**.

`const count = 3;` binds `count` to `3`. You cannot assign a new value later. That is the usual choice.

`var ready = true;` binds `ready` and allows `ready = false;` later. Use `var` only when the value must change.

The compiler checks this. If you write `const` and then assign, the program does not compile. That is a feature: the page tells you whether a name is allowed to move.

You can still give a type on either kind of binding: `const count: i32 = 3;`. If you omit the type, Zig infers it from the value when it can.
