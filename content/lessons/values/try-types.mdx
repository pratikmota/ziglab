The starter declares three values: an integer, a float, and a boolean. `ready` is `var` because it is assigned after the binding. Read the types on the left of each `=`.

`{d}` in the format string prints a number. `{}` prints the next value in a default way. The second argument to `print`, `.{ count, ratio, ready }`, is the list of values — the same `.{ }` you left empty in Hello World.

You can change a number or flip `ready` if you want. Run to see the line. Keep the print shape if you still want the expected output.
