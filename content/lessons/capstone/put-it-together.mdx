You have enough Zig to write a complete program that never leaves memory: a struct, an array, `for`, and `if`. No command-line arguments, no files, no network. The playground cannot host those honestly.

The next page is a **shelf**. Each slot has a quantity. You add the quantities that are actually there and print one number.

That is the win for this path: a program you can Run in the lab, built from chapters you already walked. After it, **What next** points at the Language Reference, Ziglings, and a local install — including `zig build` and C, which this browser will not compile.
