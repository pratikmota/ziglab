In Zig, a **type is a value** — but only at comptime. You can pass `i32` into a function the way you pass `5`, as long as the parameter is `comptime T: type`.

```zig
const std = @import("std");

fn zero(comptime T: type) T {
    return 0;
}

pub fn main() void {
    const n = zero(i32);
    std.debug.print("{d}\n", .{n});
}
```

`zero(i32)` returns an `i32` `0`. `zero(u8)` would return a `u8`. The body is still ordinary Zig: `return 0`.

You will see this pattern in the standard library: one function, many types, no copy-paste. You do not need `@Type` or a compile-time type factory for this path. Passing a type you already named is enough.
