ZigLab is a browser-first lab for learning Zig. You can read a short lesson, try an example in the playground when it is ready, and walk a path from hello world toward comptime — without installing a compiler first.

This site is an independent community project. It is not the official Zig language website, and it does not replace the language reference. For Zig itself, go to [ziglang.org](https://ziglang.org/).

## How to start

Open **Learn** and begin with Welcome, or jump to a chapter from the home page. Progress stays in this browser only. There is no account in v1.

If a lesson or the playground looks wrong, open a GitHub issue. Pull requests for original lesson prose are welcome.

Thanks for showing up early.
